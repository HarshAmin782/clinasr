# Kaggle execution

`run_clinasr.py` is GENERATED by `scripts/build_kaggle_script.py` from `src/clinasr/*.py` — never edit it
by hand. Kaggle runs it without arguments; the stage is set by `DEFAULT_STAGE` in
`src/clinasr/kaggle_entrypoint.py` (1 smoke test, 2 two-model clean run, 4 noise run incl. clean).

- `kernel-metadata.json` — private kernel, GPU (T4) and internet enabled (created by
  `scripts/kaggle_workflow.py init`).
- `stage2_selection.json` — the reviewed 300-utterance selection; the GPU run recomputes it and aborts
  before inference if its fingerprint differs.

Submit only with explicit approval: `python scripts/kaggle_workflow.py push --confirm --budget-minutes N`
(`-t` enforces the budget server-side). The workflow script derives the Bearer token the Kernels API needs
from `~/.kaggle/kaggle.json`. This kaggle CLI version has no `logs` command; console logs are in the fetched
`clinasr-medical-asr.log` and on the kernel page.
